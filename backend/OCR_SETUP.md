# OCR 图片识别功能配置说明

## 功能说明

已实现拍照上传图片识别单词的功能，支持：
- 拍照或从相册选择图片
- OCR识别图片中的英文单词
- 批量添加识别到的单词

## 配置步骤

### 1. 获取百度OCR API密钥

1. 访问 [百度智能云](https://cloud.baidu.com/)
2. 注册/登录账号
3. 进入"产品服务" -> "文字识别"
4. 创建应用，获取 `API Key` 和 `Secret Key`

### 2. 配置后端

在 `backend/configs/config.yaml` 或 `backend/configs/config.docker.yaml` 中添加 OCR 配置：

```yaml
ocr:
  baidu_api_key: "your_baidu_api_key"
  baidu_secret_key: "your_baidu_secret_key"
```

### 3. 重新生成代码

```bash
cd backend
make api
cd cmd/server
wire
```

### 4. 重启服务

```bash
docker-compose restart backend
```

## 使用说明

### 前端使用

1. 打开"添加单词"页面
2. 点击"📷 拍照识别单词"按钮
3. 选择"拍照"或"从相册选择"
4. 等待识别完成
5. 在识别结果弹窗中：
   - 查看识别到的单词
   - 为每个单词补充释义（可选）
   - 点击"添加 X 个单词"批量添加

### OCR识别说明

- **识别内容**：自动提取图片中的英文单词（至少2个字母）
- **去重处理**：自动去除重复的单词
- **置信度显示**：显示每个单词的识别置信度
- **手动编辑**：可以在添加前编辑或补充单词释义

## 注意事项

1. **API配额**：百度OCR免费版有每日调用次数限制
2. **图片格式**：支持 JPEG、PNG 等常见格式
3. **图片大小**：建议图片大小不超过 4MB
4. **识别精度**：识别精度取决于图片质量和文字清晰度

## 故障排查

如果OCR识别失败：
1. 检查配置文件中是否设置了百度OCR密钥
2. 检查网络连接是否正常
3. 检查图片是否清晰
4. 查看后端日志了解详细错误信息
