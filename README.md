# 艾宾浩斯单词背诵小程序

基于艾宾浩斯遗忘曲线原理的单词背诵微信小程序。

## 功能特点

- ✅ **添加单词**：支持添加单词和释义，设置开始背诵日期
- ✅ **智能复习**：根据艾宾浩斯遗忘曲线自动计算每天需要复习的单词
- ✅ **复习提醒**：清晰显示今天需要背诵的单词数量
- ✅ **进度跟踪**：记录每个单词的复习次数
- ✅ **本地存储**：所有数据保存在本地，无需网络

## 艾宾浩斯遗忘曲线复习间隔

根据艾宾浩斯遗忘曲线原理，复习间隔设置为：
- 第1次复习：1天后
- 第2次复习：2天后（累计3天）
- 第3次复习：4天后（累计7天）
- 第4次复习：7天后（累计14天）
- 第5次复习：15天后（累计29天）
- 第6次复习：30天后（累计59天）
- 之后：每30天复习一次

## 使用说明

### 1. 配置小程序

1. 使用微信开发者工具打开项目
2. 在 `project.config.json` 中修改 `appid` 为你的小程序 AppID
3. 如果没有 AppID，可以选择"测试号"进行开发

### 2. 添加图片资源

在项目根目录创建 `images` 文件夹，并添加以下图片：
- `home.png` / `home-active.png` - 首页图标（未选中/选中状态）
- `add.png` / `add-active.png` - 添加页面图标（未选中/选中状态）
- `empty.png` - 空状态图标（可选）

如果暂时没有图片，可以：
1. 在 `app.json` 中暂时移除 `tabBar` 配置
2. 或者使用占位图片

### 3. 开始使用

1. **添加单词**：
   - 进入"添加单词"页面
   - 输入单词和释义
   - 选择开始背诵的日期
   - 点击"添加单词"

2. **背诵单词**：
   - 进入"今日背诵"页面
   - 查看今天需要复习的单词列表
   - 复习完成后点击"已复习"按钮
   - 系统会自动安排下一次复习时间

3. **管理单词**：
   - 在"添加单词"页面可以查看所有已添加的单词
   - 可以删除不需要的单词

## 技术实现

### 艾宾浩斯算法

核心算法在 `utils/ebbinghaus.js` 中实现：

- `getTodayWords()`: 获取今天需要复习的单词列表
- `shouldReviewToday()`: 判断单词是否需要在今天复习
- `markAsReviewed()`: 标记单词为已复习
- `getNextReviewDate()`: 获取下一次复习日期

### 数据存储

使用微信小程序的本地存储 API (`wx.setStorageSync` / `wx.getStorageSync`) 保存数据：

- 单词列表存储在 `words` 键下
- 每个单词包含：ID、单词、释义、开始日期、复习次数等

## 开发注意事项

1. **日期处理**：所有日期使用 `YYYY-MM-DD` 格式存储
2. **时区问题**：使用本地时间，确保日期计算准确
3. **数据迁移**：如需升级，注意保持数据兼容性
4. **性能优化**：单词数量较多时，考虑添加分页或搜索功能
